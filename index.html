Cấu Trúc Thư Mục Ảnh `asset/image/` Trong Code

Toàn bộ thẻ <img src="asset/image/..."> đã được trỏ trực tiếp vào thư mục asset/image/. Khi bạn đặt file ảnh vào đúng thư mục dự án trên máy, web sẽ hiển thị bộ ảnh của bạn (và tự động hiển thị ảnh dự phòng sắc nét nếu file nào chưa có):

project-folder/
├── index.html
└── asset/
    └── image/
        ├── banner.jpg           (Ảnh Banner Trang Chủ)
        ├── baixe.jpg            (Ảnh Bãi Xe Trang Giới Thiệu)
        ├── xe1.jpg ... xe12.jpg (Ảnh đại diện 12 xe trong Danh Sách Xe)
        └── xe1-1.jpg ... xe1-5.jpg (5 góc ảnh chi tiết của từng xe)

Bạn có thể đổi tên ảnh trong mảng CARS_DATA ở phần <script> cuối file bất kỳ lúc nào.
